## 页面与操作

学生页面包括“预约座位”“我的预约”“到座导航”“投诉与申诉”。管理员页面包括“场地管理”和“数据统计”；场地管理分为座位管理、违约复核、设施与现场问题和投诉处理。身份切换、业务时钟、异常条件和重置集中在右上角“原型设置”。

| 任务 | 操作路径 |
|---|---|
| 预约 | 选择日期及时段，选择可预约座位，阅读并勾选预约规则，提交后查看预约结果 |
| 签到与签退 | 到达预约座位后，在“我的预约”或“到座导航”点击“扫码签到”，在扫描示意窗口点击“模拟扫码”；通过座位和时间校验后签到，使用后签退 |
| 暂离与返回 | 签到后登记暂离，15分钟内返回；保留截止不得超过预约结束时间，到期按状态规则处理 |
| 投诉与申诉 | 学生提交问题后，原类型和说明只读；点击“发起新投诉”可提交其他问题，“投诉记录”可切换查看历史；切换M1，在“投诉处理”中选择对应投诉后受理并答复；学生可用独立输入框补充材料或确认关闭。已签到且已完成的预约在“我的预约”提供“评价本次预约”入口 |
| 停用 | 切换M1，选择座位、开始及结束时间，填写原因后预览影响；立即停用使用中或暂离中的座位须确认现场已清空；截止后自动恢复，也可提前恢复 |
| 违约纠正 | 切换M1进入“违约复核”，查看签到截止时间与已核实故障时段；查看依据后填写处理理由，确认撤销违约并解除仅以该记录为依据的限制 |
| 权限拒绝 | 切换M2，查看未授权场地的拒绝页面；M2不能查看R1记录及统计 |
| 到座导引 | 从“我的预约”进入“到座路线”，选择出发入口，按图中路线前往预约座位；到达后点击“扫码签到”，模拟识别桌面二维码并校验签到 |
| 条件推荐 | 在“预约座位”设置必要插座条件、预计入口及推荐偏好，在同一座位图选择并确认；不符合设施条件的座位立即变灰且不可选 |
| 现场问题与换座 | 从当前预约进入“座位遇到问题”，提交后查看进度；选择替代座位并确认，失败保留原有效预约 |
| 设施状态维护 | M1进入“设施与现场问题”，填写核实或维修说明后更新设施；检查座位筛选与候选同步变化 |
| 统计 | 切换M1，进入统计，查看使用率及趋势图；可检查无开放日期、断网及慢请求提示 |

## 演示数据与边界

原型使用R1的四排、十六个合成座位、U01学生及M1/M2管理员账号。页面默认读取当前时间并按Asia/Shanghai显示北京时间，每秒更新。预约日期为当天及未来6天；日期和起止时间可自由选择，每次至少30分钟、每日累计不超过240分钟且不跨午夜。页面展示单次预约及其后续使用；重新开展一组独立场景时使用“重置演示”。座位编号为A01—A16；A02、A04在各自样例时段展示使用中或已预约状态，A03停用。A06、A11初始插座故障，其余座位插座正常；勾选插座条件后，故障座位变灰且不可选。布局用于说明座位选择方式，不代表真实场地平面测绘。

“原型设置”中的场景时间用于复现签到、超时及跨日场景；已有预约时不允许倒退时间。“同步北京时间”恢复实时模式，重置后也恢复实时模式。统计刷新时间按北京时间显示。统计图表使用固定的独立历史样例，不随本轮页面中的预约操作重算。样例中可用座位分钟为210，登记使用分钟为90，登记使用率为42.9%；切换无开放日期时分母为0，显示“—”。

页面为本地交互原型，不连接认证服务、数据库或真实通知渠道。页面角色切换、状态变化及请求延迟用于验证信息呈现和操作流程；服务端权限、并发一致性及故障恢复仍按开发验收标准测试。原型中的工具检查与学生可用性观察分别记录。

## 座位状态

可预约使用绿色，已选使用蓝底白字及勾选标记，不可预约使用橙黄色，停用使用灰色斜纹和虚线边框。不符合必要设施条件的座位显示深灰底白字，并注明“插座故障”；条件变化使已选座位不再符合要求时，清除选择并禁用确认按钮。每个座位同时显示状态文字。

本版停用演示为每个座位保存一条待执行或生效的停用安排；调整已保存安排前须先恢复座位。预约校验按所选时段与停用时段是否重叠判断。界面的时间判断、状态变化和投诉补充仅在浏览器内执行，刷新后重新初始化。

## 到座导引、条件推荐与现场问题

预约后从“我的预约”打开“到座路线”，选择西入口或东入口，路线随选择自动更新；到达后使用“扫码签到”扫描贴在桌面上的二维码。原型以扫描框与“模拟扫码”按钮示意，不生成二维码、不调用真实摄像头。默认模拟识别当前预约座位；“原型设置”的“扫码情境”可切换其他座位、无效码、相机不可用及响应超时。导航页只显示本人有效预约的目标，不提供重新选座入口。预约与导航共用座位位置和通道布局，路线按可通行区域的最短距离计算，可沿桌排上方或下方通道绕至侧面到座，不穿越桌椅和其他座位。匹配座位在签到窗口内完成一次签到；错座、无效码和过早扫码不签到，重复扫码返回已有结果，超过截止按原规则处理。响应超时先查看我的预约，不能将未确认结果显示为成功。原型不提供连续定位。

预约页统一提供设施筛选、推荐及座位图；推荐使用该页所选日期及时段。必要条件为可用插座，偏好可选距离预计入口较近或靠窗优先，同分按座位号排列；显示推荐理由和数据更新时间。已创建预约后该页不再选择新座位。替代座位只在“我的预约”的现场问题处理流程中提供，使用原预约剩余时段。设施故障、停用及已保留座位不满足相应条件。没有符合条件的座位时给出原因，用户可明确调整条件。

现场问题在“我的预约”点击“座位遇到问题”后展开，关联原座位和预约时段；管理员在“设施与现场问题”受理和答复，学生可补充或关闭。学生提交问题后可确认同房间替代座位；原预约编号、结束时间及签到截止保持，失败保留原座位。原型设置提供目标竞争、写入失败和响应丢失的独立情境，重复确认不重复生成换座记录。换座完成不自动关闭现场问题；原问题尚未关闭时，该原座位不再次进入报告者的替代候选。已核实的设施故障仍须登记修复，换座不会自动恢复设施状态。

管理员可以确认设施状态，观察筛选与推荐的变化。导航采用固定布局，不提供通道开闭或在线地图编辑。多预约存储、服务端竞争及真实消息不在本地原型实现范围内，按需求规格说明书验收。统计仍采用独立的四座历史样例，不代表本页十六座实时统计。
